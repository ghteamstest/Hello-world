# Hello-world

A simple Hello World Node.js application with comprehensive tests.

## Features

- Basic "Hello, World!" functionality
- Personalized greetings
- Timestamped greetings
- Comprehensive test suite
- Error handling for invalid inputs

## Installation

```bash
npm install
```

## Usage

### Run the application
```bash
npm start
```

### Run tests
```bash
npm test
```

### Run tests in watch mode
```bash
npm run test:watch
```

## Functions

- `helloWorld()` - Returns a simple "Hello, World!" message
- `greetPerson(name)` - Returns a personalized greeting for the given name
- `getTimestampedGreeting()` - Returns a greeting object with timestamp

## Testing

The application includes comprehensive tests covering:
- Basic functionality
- Input validation
- Error handling
- Edge cases
- Timestamp generation

All tests are written using Jest and can be run with `npm test`.
